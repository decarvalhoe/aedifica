# Aedifica

Aedifica is a research and product repository for an agentic architecture operating system designed for the Swiss architectural context.

The long-term objective is to support the full architectural process, from initial constraints and project knowledge to design, BIM enrichment, permitting, tendering, execution, handover, and construction management.

## Working Vision

Aedifica treats architecture as a constraint-led, evidence-based workflow:

- Bottom-up: collect authoritative sources, project documents, regulations, constraints, decisions, and evidence.
- Canonical-first: transform those sources into traceable rules, requirements, exceptions, and design obligations.
- Top-down: let agents act on architectural tools through a common API/MCP layer.
- Human-controlled: agents propose, verify, log, and request approval before critical actions.

## Core Thesis

Most small and mid-sized architecture offices already draw digitally, but much of the BIM value is lost because metadata, classifications, properties, exports, checks, and documentation are too manual.

Aedifica explores whether agentic automation can make BIM, compliance, documentation, and construction workflows usable for Swiss offices without forcing them to abandon their existing tools.

## Initial Scope

- Swiss architectural project lifecycle based on SIA phases.
- Swiss federal, cantonal, communal, parcel, program, and office-specific constraints.
- Archicad-first MVP, with future adapters for Revit, Rhino/Grasshopper, SketchUp, AutoCAD/BricsCAD, IFC, and Speckle.
- NOMOS-style project memory and canonical constraint matrix.
- Universal architecture API/MCP for agentic workflows.
- Auto-BIM enrichment, model checks, exports, permit dossiers, and construction management.
