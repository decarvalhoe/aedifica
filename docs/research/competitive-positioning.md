## Positioning Map

| Category | Examples | Decision |
|---|---|---|
| Authoring tools | Archicad, Revit, Vectorworks | Integrate. They own drawing/model authoring. |
| Swiss bauadministration | Messerli, SORBA, BBase, BauPlus | Integrate. They own transactions and established office admin. |
| Standards/procedure rails | CRB, SIA, CAMAC, simap/eBau | Respect and link. They are sources/rails, not targets to replace. |

## White Space

Aedifica should own the layer between sources and action:

```text
Swiss sources + project memory + phase-aware workflow + safe adapters
```

The defensible gap is not generic AI, drawing, or a replacement for bauadministration. It is Swiss
federal/cantonal/communal/parcel depth combined with a memory that survives from intake to handover.
