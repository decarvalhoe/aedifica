## Workflow

For competitions and mandats d'etude paralleles, Aedifica should model:

- programme;
- procedure choice;
- jury or college composition;
- submission requirements;
- questions/answers;
- evaluation and report;
- handoff into project memory when a project continues.

## Aedifica Role

Aedifica should help with checklists, source/version tracking, conflicts of interest, submission completeness,
questions/answers memory and decision traceability.

It must not replace jury judgement, procurement/legal interpretation, or paid SIA text.
