## Reading

Swiss bauadministration tools already cover transactional workflows: NPK/tendering, cost control, contracts,
invoices, site administration and defects. Aedifica should not compete head-on with these mature systems.

## Gap

The white space is project memory and source-linked reasoning:

- permit conditions carried into site readiness;
- PV tasks linked to photos, decisions and source records;
- defects linked to handover evidence;
- cost/schedule warnings tied to assumptions;
- cross-phase queries such as "why did this condition appear?"

## Product Decision

Integrate where the office already uses a bauadministration tool. Aedifica should prepare structured evidence,
tasks, assumptions and handoff records, then sync or export when an adapter exists.
