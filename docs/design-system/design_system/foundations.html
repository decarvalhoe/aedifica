§ 01 · Foundations

Tokens

Every value in the system, named. Build only with these. The full color and state model lives in Color & States; this page is the index of foundations.

§ 01.1

Color — core

Ink on warm paper, one red accent. No pure black, no pure white, no gradient.

--surface
#F3F1EC
--ink
#16171A
--accent
#C0392B
--accent-2
#908E85

The datum-red accent is the active reference line — used sparingly, never as a state and never decoratively. Provenance is carried by the six trust states (see Color & States).
