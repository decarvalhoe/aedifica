§ 10.3

React handoff

The state model maps to one tiny component. Drive everything off the State enum.

const STATE = {
  sourced:    { hue:'#1F7A44', dot:'filled' },
  computed:   { hue:'#475569', dot:'filled' },
  assumption: { hue:'#9A6A10', dot:'filled' },
  unknown:    { hue:'#84847A', dot:'hollow', border:'dashed' },
  conflict:   { hue:'#C1122C', dot:'filled' },
  decision:   { hue:'#16171A', fill:true, dot:'white' },
};

function StateChip({ state }) {
  const s = STATE[state];
  return (
    <span className={`ds-ts is-${state}`}>
      <span className="dot" /> {state}
    </span>
  );
}
Rule Never render a state with colour alone — always include the label. The .ds-ts.is-{state} class carries hue, border and dot; the JS map mirrors the CSS custom properties for convenience, not as a second source of truth.

§ 10.5

Skill prompt

What an agent should hold in mind when generating an AEDIFICA surface.

## AEDIFICA — Datum
Radical Swiss, architectonic, evidence-backed. Ink on warm paper,
square corners, hairline structure, datum lines, controlled density.

DO   · Space Grotesk (300 display / 400-500 UI) + IBM Plex Mono (annotations)
     · every claim carries a trust state (sourced…decision), colour + label
     · keep the disclaimer: "Préparation sourcée par AEDIFICA. Pas une autorité."
     · use the proprietary sprite; mark demo data DEMO

DON'T· no gradient, blob, glassmorphism, neumorphism, drop-shadow magic
     · no authority posture, no guaranteed outcome
     · no IBM Plex Sans, no third sans, no external icon library
     · never invent values — read colors_and_type.css
