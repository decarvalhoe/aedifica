§ 09 · Accessibility / QA

Legible, operable, printable

The system targets WCAG 2.2 AA on screen and full legibility in greyscale print. Because state colour never stands alone, the eight states pass the colour-blind and photocopy test by design.

§ 09.1

§ 09.3

QA checklists

Run before any surface or export ships.

Print QA

  • A4, 18mm margins, header + footer rules
  • State squares legible in greyscale
  • Every sourced claim cites a ref
  • Unknowns block present
  • Disclaimer in page footer

Responsive QA

  • Margins collapse 64 → 24 under 760px
  • Tables scroll, never crush
  • Grid drops to 2 then 1 column
  • Type scale holds (clamp)
  • Targets stay ≥ 44px

Export checklist

  • Fonts embedded / wordmark outlined
  • Assets copied, not cross-linked
  • Demo data flagged DEMO
  • No external icon library linked
  • Disclaimer present
