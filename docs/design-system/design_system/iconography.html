§ 05 · Iconography

One proprietary sprite

All icons live in a single file — assets/functional-icons.svg. Geometric, 24px grid, 1.5px stroke, square caps, drawn to match the datum drawing language. There is no external icon library and no icon-package dependency, ever.

§ 05.4

Usage & rules

  <use href="assets/functional-icons.svg#ic-parcel"/>
</svg>

.i { width:22px; height:22px;
     color: var(--ink); }
grid24px · 1.5px stroke · square caps · miter joins
colorinherits currentColor — never hard-coded
sizes16–18 inline · 22–24 controls · 26+ surface headers
familyoutline only — never mix outline + filled
emojinever — breaks the tone
Policy Icons are part of the brand. Add new glyphs to functional-icons.svg on the same 24px grid and stroke. Aucune bibliothèque externe — do not pull in or link any third-party icon set or icon-package dependency.
