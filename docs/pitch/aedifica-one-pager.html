L'OS de projet pour l'architecte suisse.

AEDIFICA assiste tout le mandat d'architecture : sources, contraintes, variantes, dessins, modèles, permis, soumissions, chantier, remise et mémoire. Le pilote réglementaire prouve la valeur, mais le produit reste un système complet d'intelligence projet et d'action multi-logiciels.

Contrat produit

Préparation sourcée par AEDIFICA. Pas une autorité. L'architecte garde la décision, le dépôt, l'arbitrage et l'approbation de toute action.

Bottom-up

Mémoire canonique.

Sources officielles, documents bureau, plans, modèle, contraintes, décisions et preuves deviennent une mémoire projet sourcée, phase-aware et réutilisable.

Top-down

Agents d'architecture.

Les agents cadrent, comparent, vérifient, rédigent, coordonnent et proposent les prochaines actions du mandat sans sortir du contrat de preuve.

Exécution

API multi-logiciels.

Archicad d'abord, puis IFC, Speckle, Revit, Rhino, SketchUp, AutoCAD/BricsCAD : inspection, intention de dessin, modèle, export, dry-run, approbation, ledger.
